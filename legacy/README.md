# Legacy: installation without Docker (not maintained)

Before the Docker image, MyServices ran from a folder with systemd units generated by `install.sh`
(timers for the collection, the watcher, the health and backup checks, a small API for the refresh
button, and an nginx or Apache snippet). This is **no longer maintained or tested** since 0.28.0:
the files are kept here as a reference only. Use the Docker image (see the README).

The Python modules now live in the `msv` package, so the units and `install.sh` that start
`watcher.py`, `health.py`, `backups.py` or `myservices.py` by file name no longer work as they are
(`python3 -m msv.collect.watcher`, and so on).
